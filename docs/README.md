# 文档总览

## 当前权威文档

- [PLAN.md](./PLAN.md): 架构、接口、数据模型、阶段计划的权威设计文档
- [architecture.md](./architecture.md): 当前项目结构与职责划分
- [development.md](./development.md): 本地开发、测试与联调方式
- [production.md](./production.md): 生产构建、部署与运行方式
- [api.md](./api.md): 后端对前端暴露的接口说明

## 文档使用顺序

1. 先看 [PLAN.md](./PLAN.md) 理解边界与设计。
2. 再看 [architecture.md](./architecture.md) 理解目录与职责。
3. 开发时看 [development.md](./development.md)。
4. 部署时看 [production.md](./production.md)。
5. 对接接口时看 [api.md](./api.md)。

## 历史与参考材料

`frontend/docs/` 中保留了参考前端项目的一些文档与截图，主要用于：

- 保留原项目交互与视觉参考
- 追溯旧的纯前端能力
- 对照当前“后端代理化”改造前后的差异

这些内容不是当前项目的权威运行文档。
